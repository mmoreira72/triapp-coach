# Challenge Salou-Costa Daurada, T100 distance (9 May 2027)

From the organiser's Google My Maps embedded at https://challenge-salou.com/en/distances/t100-distance/ (saved as
`official/map.kml`; the map is titled "maps to test before publishing", so it may still change): one 26.7 km bike loop on the
highway, ridden 3 times (`race.json` carries the official 80 km), and one 4.25 km run lap, run 4 times plus the link to
transition (official 18 km). The 2-lap swim off Salou beach is not drawn: `swim.gpx` is schematic (official 2 km).
Elevation from the DEM; the organiser gives no ascent figure, and the bike profile is smoothed hard (a fast highway course).
Weather: ERA5 reanalysis, 29 April - 19 May, 08:00-14:00, 2016-2025. Water 16-18 °C assumed for early May.
